## What's in v0.5.2

**Heads-up if you installed an earlier version:** the app's ID changed to `com.nishithdevstudios.usageguard`, ready for Google Play. Android treats this as a new app, so it installs **next to** the old one instead of updating it.

1. Install this version and set up your limits and groups again.
2. Uninstall the old Usage Guard. Long-press its icon → Uninstall. The new one is the version shown at the bottom of Settings.
3. If you set up NFC tags, write them again from the Tags tab.

### Changes
- Targets Android 16 (API level 36)
- The Back button works on the lock layer with Android 16's predictive back
- Setup screen no longer slides under the status bar
- Battery setup now opens Usage Guard's App info page. Choose **App battery usage → Unrestricted**. The app no longer asks for the "ignore battery optimization" permission.
- Settings shows the real app version
